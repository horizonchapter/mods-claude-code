# Contribuer à Mods Claude Code

Les idées et corrections sont bienvenues.

1. Ouvre une **issue** (modèles fournis) pour décrire le problème ou l'idée.
2. Pour proposer un changement : fork, branche, modification, pull request.
3. Teste dans Claude Code : installe ta version avec `/plugin marketplace add ./` puis `/plugin install <mod>@mods-perso`, et lance les tests du mod (`claude plugin test <dossier-du-mod>`).
4. Garde chaque mod **petit et indépendant** : un mod ne dépend jamais d'un autre.
5. Exemples toujours **fictifs** : aucune donnée réelle, aucune clé.
